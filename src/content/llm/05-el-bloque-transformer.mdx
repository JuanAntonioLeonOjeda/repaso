La atención deja que cada token mire a los demás. Un **bloque transformer** añade lo que falta para apilar decenas de ellos sin que el entrenamiento se rompa: una pequeña red densa que procesa cada token por separado, conexiones residuales y normalización. GPT-2, Llama y el modelo de este tutorial son eso mismo repetido: aquí 6 bloques; en los modelos grandes, entre 30 y más de 100.

## El bloque

```python
class Block(nn.Module):
    def __init__(self, d, heads, dropout):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.attn = CausalSelfAttention(d, heads, dropout)
        self.mlp = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d), nn.Dropout(dropout))

    def forward(self, x):
        x = x + self.attn(self.ln1(x))     # los tokens se comunican
        return x + self.mlp(self.ln2(x))   # cada token piensa por su cuenta
```

- **Atención**: comunicación entre tokens.
- **MLP**: cálculo dentro de cada token, con una capa oculta 4 veces más ancha y activación GELU. Aquí está la mayor parte de los parámetros, y es donde se cree que se guarda buena parte del "conocimiento".
- **Conexiones residuales** (`x + ...`): cada subcapa añade una corrección a $x$ en vez de sustituirlo.
- **LayerNorm antes de cada subcapa** (*pre-norm*, como en GPT-2): normaliza cada vector de token a media 0 y varianza 1, con una escala y un desplazamiento aprendidos.

## El modelo completo

```python
class GPT(nn.Module):
    def __init__(self, layers=6, d=384, heads=6, dropout=0.2):
        super().__init__()
        self.tok_emb = nn.Embedding(VOCAB, d)          # 2.048 tokens
        self.pos_emb = nn.Embedding(CONTEXT, d)        # 256 posiciones aprendidas, como en GPT-2
        self.drop = nn.Dropout(dropout)
        self.blocks = nn.ModuleList(Block(d, heads, dropout) for _ in range(layers))
        self.ln_f = nn.LayerNorm(d)
        self.head = nn.Linear(d, VOCAB, bias=False)
        self.head.weight = self.tok_emb.weight         # pesos compartidos (weight tying)
        self.apply(self._init_weights)                 # pesos pequeños (std 0,02), como en GPT-2

    def forward(self, idx):
        pos = torch.arange(idx.shape[1], device=idx.device)
        x = self.drop(self.tok_emb(idx) + self.pos_emb(pos))
        for block in self.blocks:
            x = block(x)
        return self.head(self.ln_f(x))                 # (B, T, 2.048): una distribución por posición
```

La atención no sabe nada del orden: si barajas los tokens, cada uno ve el mismo conjunto. Por eso a cada token se le suma un **embedding de posición**. Aquí son 256 vectores aprendidos, uno por posición de la ventana. Los modelos modernos usan RoPE, que rota las consultas y las claves según la posición: codifica la posición relativa y, con ajustes de escala, se adapta mejor a contextos más largos.

<Callout kind="real" title="En el trabajo">
- **Los modelos actuales cambian detalles, no la receta**: RMSNorm en vez de LayerNorm, SwiGLU en vez de GELU, RoPE en vez de posiciones aprendidas, atención con menos claves y valores (GQA) y, en algunos, *mixture of experts* (varios MLP y un router que elige cuáles usar para cada token).
- **Lee el `config.json`** de cualquier modelo en Hugging Face: `num_hidden_layers`, `hidden_size`, `num_attention_heads`, `vocab_size`… son exactamente los números de esta lección.

</Callout>

## Para llevar

- Bloque = LayerNorm → atención → residual, LayerNorm → MLP → residual.
- Las residuales dan al gradiente un camino directo y permiten apilar muchos bloques.
- Posiciones: un embedding por posición, sumado al del token. Salida: la matriz de embeddings compartida.
- Nuestro GPT: 6 bloques, $d = 384$, 6 cabezas, 11.532.288 parámetros. Unos $12 d^2$ por bloque.
