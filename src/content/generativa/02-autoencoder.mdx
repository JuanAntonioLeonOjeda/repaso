El primer paso hacia un generador no genera nada: comprime. Un **autoencoder** es una red que aprende a reconstruir su entrada pasando por un cuello de botella. Si consigue escribir un dígito de 784 píxeles con solo **dos números** y recuperarlo después, esos dos números tienen que capturar lo esencial del dígito. A ese espacio pequeño se le llama **espacio latente**, y es la pieza que reutilizan el VAE, la difusión latente y Stable Diffusion.

## Codificador, cuello de botella y decodificador

```python
from torch import nn
import torch.nn.functional as F

LATENT = 2

class Encoder(nn.Module):
    def __init__(self, out):
        super().__init__()
        self.net = nn.Sequential(nn.Flatten(), nn.Linear(784, 512), nn.ReLU(),
                                 nn.Linear(512, 256), nn.ReLU(), nn.Linear(256, out))
    def forward(self, x):
        return self.net(x)

class Decoder(nn.Module):
    """Vector latente -> logits de 28×28 (la sigmoide da la imagen)."""
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(LATENT, 256), nn.ReLU(), nn.Linear(256, 512), nn.ReLU(),
                                 nn.Linear(512, 784), nn.Unflatten(1, (1, 28, 28)))
    def forward(self, z):
        return self.net(z)

class Autoencoder(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder, self.decoder = Encoder(LATENT), Decoder()
    def forward(self, x):
        z = self.encoder(x)            # (B, 2): el dígito resumido en dos números
        return self.decoder(z), z
```

Se entrena para que la salida se parezca a la entrada, píxel a píxel. Como los píxeles de MNIST están en $[0, 1]$, la pérdida es la **entropía cruzada binaria** de cada píxel, sumada sobre la imagen: cada píxel es "cuánta tinta hay". No hacen falta etiquetas: es aprendizaje no supervisado.

## Lo que aprende

20 épocas con Adam (`lr=1e-3`), unos 3 segundos cada una en MPS. La pérdida de reconstrucción baja de 174 a 132,5 en train y queda en 133,1 en test: con dos números por imagen, el autoencoder recupera la forma general del dígito, aunque borrosa.

    from sklearn.datasets import load_digits

    X = load_digits().data                      # 1.797 dígitos de 8×8 = 64 píxeles
    media = X.mean(axis=0)
    Xc = X - media
    _, _, Vt = np.linalg.svd(Xc, full_matrices=False)   # filas de Vt: componentes principales

        return Z @ W + media                    # (n, 64): la reconstrucción

## Por qué no sabe generar

Para generar habría que elegir un punto del espacio latente y decodificarlo. Pero ¿qué punto? El autoencoder no dice nada de cómo se reparten los códigos. Si sorteas puntos de una gaussiana estándar $\mathcal{N}(0, I)$, caen en la zona central, donde el decodificador sí ha visto dígitos:

![32 dígitos decodificados por el autoencoder a partir de puntos sorteados de una gaussiana estándar](/tutorials/generativa/muestras-ae.png)

Salen dígitos, reconocibles en su mayoría, pero **no todos los dígitos**. El clasificador de la lección 7, aplicado a 2.000 muestras como estas, encuentra solo **2 unos y 91 ceros**, frente a más de 300 doses y cincos (con todos los dígitos igual de representados saldrían unos 200 de cada). Los brazos de los 0 y los 1 están a decenas de unidades del origen, y una gaussiana estándar casi nunca llega tan lejos. Y si sorteas en todo el rango, caes en los huecos entre brazos, donde el decodificador nunca vio nada y produce manchas.

<Callout kind="real" title="En el trabajo">
- **Los autoencoders siguen muy vivos, pero no para generar.** Se usan para comprimir (el VAE de Stable Diffusion, lección 8), para detectar anomalías (lo que se reconstruye mal es raro) y para eliminar ruido (*denoising autoencoders*).
- **Detección de anomalías**: se entrena solo con piezas buenas; una pieza con un defecto se reconstruye peor, y el error de reconstrucción sirve de alarma. Es uno de los usos industriales más habituales.
- **Más dimensiones latentes, mejor reconstrucción.** Aquí se usan 2 para poder dibujarlas; en la práctica, decenas o cientos.
</Callout>

## Para llevar

- Autoencoder: codificador → cuello de botella → decodificador, entrenado a reconstruir, sin etiquetas.
- Su espacio latente agrupa dígitos parecidos, pero es irregular y está lleno de huecos.
- Por eso no sabe generar: no hay una distribución conocida de la que sacar códigos.
- PCA es el caso lineal; las capas no lineales permiten espacios latentes curvos.
