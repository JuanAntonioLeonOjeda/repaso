El VAE genera dígitos variados pero borrosos, porque su pérdida compara píxel a píxel y premia el promedio. Una **GAN** cambia la pregunta: en vez de "¿se parece píxel a píxel a una imagen real?", pregunta "¿una red entrenada para detectar falsificaciones la distingue de una real?". El juego del falsificador y el policía ya lo viste en la asignatura. Aquí lo montas en PyTorch con convoluciones (una **DCGAN**) y aprendes lo que la teoría no cuenta: cómo se escribe el bucle y cómo saber si está funcionando.

## Generador y discriminador

El generador hace lo contrario que una CNN de clasificación: parte de un vector de ruido de 100 números y lo va ampliando con **convoluciones traspuestas** hasta tener una imagen de 28×28.

```python
Z_DIM = 100

class Generator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(Z_DIM, 128 * 7 * 7), nn.Unflatten(1, (128, 7, 7)), nn.BatchNorm2d(128), nn.ReLU(),
            nn.ConvTranspose2d(128, 64, 4, stride=2, padding=1), nn.BatchNorm2d(64), nn.ReLU(),  # 14×14
            nn.ConvTranspose2d(64, 1, 4, stride=2, padding=1), nn.Tanh(),                        # 28×28 en [-1, 1]
        )
    def forward(self, z):
        return self.net(z)

class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 64, 4, stride=2, padding=1), nn.LeakyReLU(0.2),                         # 14×14
            nn.Conv2d(64, 128, 4, stride=2, padding=1), nn.BatchNorm2d(128), nn.LeakyReLU(0.2),  # 7×7
            nn.Flatten(), nn.Linear(128 * 7 * 7, 1),                                             # un logit: "real"
        )
    def forward(self, x):
        return self.net(x).squeeze(1)
```

Las recetas de la DCGAN que aparecen aquí: `Tanh` a la salida del generador (y las imágenes reales normalizadas a $[-1, 1]$ para que coincidan), `BatchNorm` en las dos redes, `LeakyReLU` en el discriminador para que el gradiente no se apague con activaciones negativas, y `stride=2` en vez de pooling.

## El bucle: dos optimizadores y un detach

```python
G, D = Generator().to(device), Discriminator().to(device)
opt_g = torch.optim.Adam(G.parameters(), lr=2e-4, betas=(0.5, 0.999))
opt_d = torch.optim.Adam(D.parameters(), lr=2e-4, betas=(0.5, 0.999))
bce = nn.BCEWithLogitsLoss()

for real, _ in loader:                                   # imágenes en [-1, 1]; las etiquetas no se usan
    ones, zeros = torch.ones(len(real)), torch.zeros(len(real))
    # 1) Discriminador: reales -> 1, falsas -> 0
    fake = G(torch.randn(len(real), Z_DIM))
    loss_d = bce(D(real), ones) + bce(D(fake.detach()), zeros)
    opt_d.zero_grad(); loss_d.backward(); opt_d.step()
    # 2) Generador: que D diga "real" de las falsas (pérdida no saturante)
    loss_g = bce(D(fake), ones)
    opt_g.zero_grad(); loss_g.backward(); opt_g.step()
```

Dos detalles que separan una GAN que funciona de una que no:

- **Cada red tiene su optimizador**, y cada paso solo mueve los parámetros de una. `opt_d.step()` no toca $G$ y `opt_g.step()` no toca $D$, aunque el gradiente de `loss_g` atraviese $D$ para llegar a $G$.
- **`betas=(0.5, 0.999)`**: un momento más corto que el de Adam por defecto (0,9). En un juego entre dos redes, el objetivo de cada una cambia en cada paso, y un momento largo arrastra demasiada historia.

20 épocas sobre los 60.000 dígitos. Las mismas 16 entradas de ruido, decodificadas por el generador al final de las épocas 1, 5 y 20 (una fila por época):

En la época 1 hay manchas con forma vagamente de dígito. En la 5 ya se reconocen casi todos, con trazos rotos. <Callout kind="real" title="En el trabajo">
- **Las GAN han cedido el terreno a la difusión** en generación de imágenes: entrenan de forma inestable y tienden al *mode collapse*. Siguen vivas donde importa la velocidad, porque generan en **una sola pasada** (la difusión necesita muchas): superresolución en tiempo real, traducción imagen a imagen, y como pérdida adicional para afinar otros modelos (el «adversarial» de SD-Turbo, lección 8).
- **Si entrenas una**: guarda una cuadrícula de muestras con ruido fijo en cada época, como aquí. Es la forma más rápida de ver si aprende, si se estanca o si colapsa.
- **Trucos habituales** cuando no converge: suavizar las etiquetas reales (0,9 en vez de 1), *spectral normalization* en el discriminador, o pasar a una pérdida tipo WGAN-GP.
</Callout>
