TF-IDF convierte un texto en un vector de recuentos y se olvida del orden. Las redes de las próximas lecciones leen el texto **como una secuencia**: un número por cada trozo de texto, en orden. Ese paso, de texto a lista de números, se llama **tokenizar**, y sus decisiones (qué es un trozo, qué hacer con las palabras que no conoces, cómo meter en un lote textos de distinta longitud) se arrastran hasta producción.

## De texto a ids

La versión más sencilla: partir en palabras y signos, pasar a minúsculas, construir un **vocabulario** con las palabras frecuentes de train y dar a cada una un número. Dos ids se reservan: `<pad>` (0) para rellenar y `<unk>` (1) para lo que no está en el vocabulario.

```python
import re
from collections import Counter

TOKEN = re.compile(r"\w+|[^\w\s]")      # palabras o signos sueltos
PAD, UNK = 0, 1

def tokenize(text):
    return TOKEN.findall(text.lower())

def build_vocab(texts, max_size=30_000, min_freq=2):
    counts = Counter(tok for t in texts for tok in tokenize(t))
    words = [w for w, c in counts.most_common(max_size - 2) if c >= min_freq]
    return {"<pad>": PAD, "<unk>": UNK, **{w: i + 2 for i, w in enumerate(words)}}

def encode(text, vocab, max_len=128):
    return [vocab.get(tok, UNK) for tok in tokenize(text)][:max_len] or [UNK]
```

Con las 200.000 reseñas, el vocabulario se llena con las 30.000 palabras más frecuentes. Así queda una reseña:

```python
tokenize("Llegó desconfigurado y el vendedor no contesta.")
# ['llegó', 'desconfigurado', 'y', 'el', 'vendedor', 'no', 'contesta', '.']
encode("Llegó desconfigurado y el vendedor no contesta.", vocab)
# [83, 14415, 6, 9, 134, 8, 2456, 2]
```

Las palabras frecuentes reciben ids bajos («y» es el 6, «no» el 8); «desconfigurado» es la 14.415. El punto es el 2: el token más frecuente de todos.

## Lotes: relleno y máscara

Una red procesa lotes, y un lote es un tensor rectangular. Las reseñas tienen longitudes distintas, así que se **rellenan** con `<pad>` hasta la más larga **del lote** y se acompaña de una **máscara** que dice qué posiciones son texto de verdad. Rellenar hasta la más larga del lote, y no hasta un máximo fijo, ahorra mucho cálculo con textos cortos.

## Palabras desconocidas y subpalabras

Un vocabulario de palabras tiene dos problemas. Las palabras que no están se convierten todas en `<unk>`: un modelo de producto, una errata, una conjugación rara. Y el vocabulario no puede crecer sin fin, porque cada palabra necesita su propio vector.

Con 30.000 palabras y 200.000 reseñas de train, el problema es pequeño aquí: solo el **0,81% de los tokens de validación** cae en `<unk>`. Pero con menos datos o textos más técnicos crece rápido, y toda palabra nueva que aparezca en producción se pierde.

Los transformers lo resuelven con **subpalabras**: el vocabulario tiene palabras frecuentes enteras y trozos (raíces, sufijos, sílabas, letras), y cualquier palabra se puede escribir como una secuencia de trozos. BETO usa *WordPiece* con un vocabulario de 31.002 piezas:

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("dccuchile/bert-base-spanish-wwm-cased")
tokenizer.tokenize("Llegó desconfigurado y el vendedor no contesta.")
```

```python
['Llegó', 'desconfi', '##gura', '##do', 'y', 'el', 'vendedor', 'no', 'contesta', '.']
```

Las palabras frecuentes son una sola pieza. «desconfigurado» se parte en tres: `desconfi`, `##gura` y `##do` (el `##` indica que la pieza continúa la anterior). Ninguna palabra se queda fuera, y BETO respeta las mayúsculas: «Llegó» y «llegó» son piezas distintas.

## Truncar

Cada red tiene un límite de longitud: BETO, 512 tokens. Y aunque no lo hubiera, procesar secuencias largas cuesta: un transformer hace un cálculo cuadrático con la longitud. Se elige un `max_length` mirando la distribución de longitudes y se corta lo que sobra.

<Callout kind="real" title="En el trabajo">
- **Usa el tokenizador del modelo, siempre.** Un modelo preentrenado solo entiende los ids de su propio tokenizador. Se cargan juntos (`AutoTokenizer` y `AutoModel` con el mismo nombre) y se guardan juntos.
- **Normaliza con cuidado.** Pasar a minúsculas o quitar tildes reduce el vocabulario, pero borra información: «NO FUNCIONA» grita, y en español «sí» y «si» no son lo mismo. BETO tiene versión *cased* (respeta mayúsculas) y *uncased*; aquí se usa la *cased*.
- **Mira cuántos tokens produce tu texto.** Los límites (y la factura, en las API de LLM) se cuentan en tokens, no en palabras, y en español cada palabra produce más tokens que en inglés con los tokenizadores entrenados sobre todo en inglés.
</Callout>
