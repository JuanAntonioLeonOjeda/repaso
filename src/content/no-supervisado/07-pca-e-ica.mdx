Tienes 50 columnas, pero muchas dicen casi lo mismo (altura y peso, ingresos y gasto…). Reducir la dimensionalidad es **cambiar de ejes** para describir los datos con menos números sin perder lo importante. Sirve para visualizar, para quitar ruido, para acelerar modelos y para combatir la maldición de la dimensionalidad.

## PCA: análisis de componentes principales

PCA busca **nuevos ejes** (las componentes principales) con dos propiedades:

1. La **primera** componente es la dirección en la que los datos tienen **más varianza** (más "información").
2. Cada componente siguiente es **perpendicular** a las anteriores y recoge la máxima varianza restante.

Cada componente es una combinación lineal de las variables originales. Al quedarte con las $q$ primeras, proyectas los datos a $q$ dimensiones perdiendo lo mínimo.

<PcaSim />

### Cómo se calcula (y por qué salen vectores propios)

1. **Centra** los datos (resta la media de cada columna) y, si las variables tienen unidades distintas, **estandarízalas**. Si no, la variable con números más grandes dominará la primera componente solo por su escala.
2. Calcula la **matriz de covarianzas** $\Sigma$.
3. Sus **vectores propios** son las direcciones de las componentes y sus **valores propios**, la varianza que recoge cada una.
4. Proyecta: $Z = X_{\text{centrado}} \cdot V_q$.

La proporción de varianza explicada de la componente $j$ es $\lambda_j / \sum_i \lambda_i$.

## ICA: análisis de componentes independientes

PCA busca direcciones **incorreladas** con máxima varianza. ICA busca algo más fuerte: **fuentes estadísticamente independientes** que, mezcladas, producen lo que observas.

El ejemplo clásico es el **problema del cóctel**: varias personas hablan a la vez y varios micrófonos graban mezclas distintas. ICA recupera cada voz por separado. Formalmente, observamos $X = S A^\top$ (fuentes $S$ mezcladas por una matriz $A$ desconocida) y ICA estima una matriz $W$ tal que $S \approx X W^\top$.

Su suposición clave: las fuentes son **independientes y no gaussianas** (si fueran gaussianas, cualquier rotación serviría y no habría solución única). Por eso maximiza la "no gaussianidad" (FastICA).

<RunCode
  title="Separar señales mezcladas con FastICA"
  code={`
    import numpy as np
    import matplotlib.pyplot as plt
    from sklearn.decomposition import FastICA, PCA

    t = np.linspace(0, 8, 2000)
    s1 = np.sin(2 * t)                       # una sinusoide
    s2 = np.sign(np.sin(3 * t))              # una onda cuadrada
    s3 = ((t * 1.7) % 2) - 1                 # un diente de sierra
    S = np.c_[s1, s2, s3]
    S += 0.1 * np.random.default_rng(0).normal(size=S.shape)

    A = np.array([[1, 1, 1], [0.5, 2, 1.0], [1.5, 1.0, 2.0]])   # mezcla
    X = S @ A.T                                                  # lo que graban los "micrófonos"

    S_ica = FastICA(n_components=3, random_state=0).fit_transform(X)
    S_pca = PCA(n_components=3).fit_transform(X)

    fig, axes = plt.subplots(4, 1, figsize=(9, 7), sharex=True)
    for ax, data, title in zip(axes, [S, X, S_ica, S_pca],
                               ["Fuentes reales", "Mezclas observadas", "ICA recupera", "PCA (no separa)"]):
        ax.plot(t[:600], data[:600]); ax.set_title(title, fontsize=10)
    plt.tight_layout(); plt.show()
  `}
/>

Fíjate: ICA recupera las tres formas (aunque **con el orden y la escala cambiados**: es una ambigüedad inevitable). PCA solo las descorrelaciona, sin separarlas.

<Callout kind="real">
ICA se usa sobre todo en **señales**: limpiar electroencefalogramas (separar el parpadeo de la actividad cerebral), separar fuentes de audio, imagen médica funcional. PCA, en cambio, está en todas partes: preprocesado antes de un modelo, compresión, visualización, detección de anomalías (lo que se reconstruye mal con pocas componentes es raro) y como paso interno de muchos métodos.
</Callout>

## Para llevar

- PCA: nuevos ejes perpendiculares ordenados por varianza = vectores propios de la covarianza.
- Centra y estandariza antes. Quédate con las componentes que expliquen ~95%.
