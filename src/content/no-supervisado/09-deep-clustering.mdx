K-means sobre píxeles crudos funciona regular: dos fotos del mismo perro con distinta luz están "lejos" píxel a píxel. El **deep clustering** usa una red neuronal para transformar los datos en un **espacio latente** donde las distancias tienen sentido, y agrupa ahí. Esta lección conecta lo no supervisado con Deep Learning (si aún no la has repasado, verás conceptos que se explican allí).

## Autoencoders: comprimir para entender

Un **autoencoder** es una red que aprende a **reconstruir su entrada** pasando por un cuello de botella:

- El **codificador** comprime la entrada $x$ en un vector pequeño $z$ (el espacio latente).
- El **decodificador** intenta reconstruir $x$ a partir de $z$.
- Se entrena minimizando el error de reconstrucción. No necesita etiquetas.

Para reconstruir bien con tan poco espacio, la red se ve obligada a guardar en $z$ lo **esencial** de los datos. Ese $z$ es una representación compacta y mucho mejor para agrupar que los píxeles.

## DEC y DCN: agrupar mientras se aprende

Agrupar sobre un espacio latente fijo ya mejora mucho, pero se puede ir más allá: **ajustar el codificador para que el espacio latente sea más "agrupable"**.

**DEC (Deep Embedded Clustering)**, el del notebook:

1. Preentrena el autoencoder y quédate con el codificador.
2. Inicializa los centroides con k-means sobre el espacio latente.
3. Calcula una asignación blanda de cada punto a cada centroide con una t de Student:
   $$q_{ij} = \frac{(1 + \lVert z_i - \mu_j \rVert^2)^{-1}}{\sum_{j'} (1 + \lVert z_i - \mu_{j'} \rVert^2)^{-1}}$$
4. Construye una **distribución objetivo** $p$ que "afila" $q$ (eleva al cuadrado y normaliza: refuerza las asignaciones seguras) y entrena el codificador y los centroides para minimizar $KL(p \,\|\, q)$.

**DCN (Deep Clustering Network)** es parecido pero optimiza a la vez el error de reconstrucción y una pérdida tipo k-means en el espacio latente, para que la red no "olvide" los datos mientras agrupa.

## Otras familias

- **VAE (autoencoder variacional) → VaDE**: el codificador no da un punto sino una **distribución** (media y varianza) y el espacio latente se fuerza a seguir una gaussiana. VaDE usa como prior una **mezcla de gaussianas**: cada componente es un cluster. Es como un GMM en el espacio latente, entrenado de punta a punta.
- **GAN → InfoGAN**: una GAN aprende a generar datos; InfoGAN añade al ruido de entrada un **código categórico** y fuerza a que la imagen generada conserve información sobre él. Sin etiquetas, el código acaba representando categorías (en MNIST, el dígito).
- **Métodos directos (JULE…)**: sin autoencoder ni generador, alternan agrupar (clustering jerárquico) y ajustar la red con esos grupos como pseudo-etiquetas.

<Callout kind="real">
En la práctica, hoy rara vez se entrena un autoencoder propio para agrupar: se usa un **modelo preentrenado** (una CNN o ViT para imágenes, un *sentence transformer* para texto) como codificador, se obtienen *embeddings* y sobre ellos se aplica UMAP + HDBSCAN o k-means. Es exactamente el patrón de herramientas como BERTopic. Los inconvenientes de la familia deep clustering siguen siendo los del tema: muchos hiperparámetros, mucho cómputo y resultados difíciles de interpretar.

## Para llevar

- Deep clustering = aprender un espacio latente donde agrupar tenga sentido.
- Autoencoder: codificador + decodificador entrenados para reconstruir; el cuello de botella es la representación.
- DEC refina codificador y centroides con asignaciones blandas $q$ y un objetivo afilado $p$.
- VaDE (VAE + GMM), InfoGAN (GAN con código categórico), JULE (pseudo-etiquetas).
- En la práctica: embeddings de un modelo preentrenado + clustering clásico.
