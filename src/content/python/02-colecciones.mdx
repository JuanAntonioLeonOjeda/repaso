Casi todo programa de datos mueve colecciones: una lista de ficheros, un diccionario de parámetros, un conjunto de etiquetas vistas. Elegir bien la colección hace el código más corto **y** más rápido: buscar en una lista de un millón de elementos tarda un millón de pasos; en un `set`, uno.

## Las cuatro colecciones

| | Sintaxis | Ordenada | Mutable | Duplicados | Para qué |
|---|---|---|---|---|---|
| `list` | `[1, 2, 2]` | sí | sí | sí | secuencias que crecen |
| `tuple` | `(1, 2)` | sí | **no** | sí | registros fijos, claves de dict, devolver varios valores |
| `dict` | `{"a": 1}` | sí (orden de inserción) | sí | claves únicas | buscar por clave |
| `set` | `{1, 2}` | no | sí | **no** | pertenencia, quitar duplicados, operaciones de conjuntos |

Detalles que caen:

- `{}` es un **dict vacío**; el set vacío es `set()`.
- Una tupla de un elemento lleva coma: `(5,)`. Sin ella, `(5)` es solo un 5 entre paréntesis.
- Las claves de un dict tienen que ser **inmutables** (*hashables*): `str`, `int`, `tuple`… nunca una lista.
- **Desempaquetado**: `x, y = (3, 4)`, `primero, *resto = [1, 2, 3]` y el intercambio `a, b = b, a`.

### Diccionarios: lo que más se usa

```python
persona = {"nombre": "Ana", "edad": 35}
persona["ciudad"] = "Valencia"          # añadir o modificar
persona.get("dni")                      # None en vez de KeyError
persona.get("dni", "desconocido")       # con valor por defecto
for clave, valor in persona.items():    # recorrer pares
    print(clave, valor)
"edad" in persona                       # ¿existe la clave? (no busca en los valores)
```

### Sets: pertenencia y álgebra

`a | b` (unión), `a & b` (intersección), `a - b` (diferencia) y `a ^ b` (diferencia simétrica: en uno pero no en los dos). `x in conjunto` es instantáneo, se tenga un elemento o un millón.

## Indexar y trocear

Las secuencias (`list`, `tuple`, `str`) se indexan desde 0 y admiten índices negativos (`s[-1]` es el último). El *slicing* `s[inicio:fin:paso]` incluye el inicio y **excluye** el fin; cualquiera de los tres se puede omitir.

## Copias superficiales y profundas

`lista.copy()`, `list(lista)` y `lista[:]` hacen una **copia superficial**: lista nueva, pero los elementos son los mismos objetos. Con listas de números da igual; con listas de listas, no. Para copiar también el interior: `copy.deepcopy(lista)`. Repasa el escenario «Copia superficial» de la simulación de la lección anterior si dudas.

## Comprehensions

Una *comprehension* construye una colección en una línea a partir de otra:

```python
cuadrados = [x ** 2 for x in range(10)]                 # list
pares = [x for x in range(10) if x % 2 == 0]            # con filtro
signos = ["+" if x >= 0 else "-" for x in [3, -1, 0]]   # con if/else (va ANTES del for)
longitudes = {palabra: len(palabra) for palabra in ["ia", "datos"]}   # dict
letras = {c for c in "mississippi"}                     # set: {'m', 'i', 's', 'p'}
```

Fíjate en las dos posiciones del `if`: **al final filtra** (decide qué elementos entran), **delante del `for` con `else` transforma** (decide qué valor toma cada elemento).

## Contar y buscar repetidos

Dos clásicos que aparecen en todos los exámenes y entrevistas.

        vistos = set()
        for x in arr:
            if x in vistos:

    assert repeated_element([5, 1, 1, 5]) == 1, "Debe devolver el primero que se REPITE (el 1 se repite antes que el 5)"

<Callout kind="real" title="Por qué importa el set">
La solución que circulaba en el examen guardaba los vistos en una **lista**: `if i not in checked` recorre la lista entera cada vez, así que con n elementos hace del orden de n² comparaciones. Con un `set` cada consulta es casi instantánea (es una tabla hash) y el total es lineal. Con 10 elementos no se nota; con un millón de identificadores de usuario es la diferencia entre un segundo y un día.
</Callout>

## Para llevar

- `list` para secuencias, `tuple` para registros fijos, `dict` para buscar por clave, `set` para pertenencia y quitar duplicados.
- El slicing incluye el inicio y excluye el fin; los negativos cuentan desde el final.
- `copy()` es superficial: las listas de dentro se comparten. `copy.deepcopy` copia todo.
- En una comprehension, el `if` del final filtra y el `if/else` del principio transforma.
- `dict.get(k, defecto)` evita `KeyError`; `x in set` es instantáneo.
