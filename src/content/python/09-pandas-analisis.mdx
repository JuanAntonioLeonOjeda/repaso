## Aplicar funciones: map, apply y lo vectorizado

```python
df["Status"] = df["Delay_Minutes"].apply(clasificar)      # una función por elemento
df["Sex"].map({"male": 0, "female": 1})                    # traducir con un dict
df.apply(lambda fila: fila["a"] - fila["b"], axis=1)       # una función por FILA (lento)
```

`apply` es un bucle de Python disfrazado. Funciona, pero si existe una operación vectorizada es mucho más rápida: `df["a"] - df["b"]` en vez del `apply` por filas, `np.where(cond, x, y)` para un si/no, y `pd.cut` para tramos:

```python
df["Status"] = pd.cut(df["Delay_Minutes"], bins=[-np.inf, 15, 60, np.inf],
                      labels=["A tiempo", "Retrasado", "Cancelado"], right=False)
```

## Agrupar: groupby

<GroupBySim />

```python
df.groupby("Airline")["Delay_Minutes"].mean()                    # una Series
df.groupby("Airline")["Delay_Minutes"].agg(["mean", "median", "count"])
df.groupby(["Pclass", "Sex"])["Survived"].mean()                 # varias claves: índice doble
df.groupby("Airline").agg(media=("Delay_Minutes", "mean"),       # agregación con nombres
                          vuelos=("Flight_Number", "count"))
df.groupby("Airline")["Delay_Minutes"].transform("mean")         # un valor POR FILA
df.groupby("Airline").filter(lambda g: len(g) >= 10)             # quitar grupos enteros
```

La clave para no liarse: `agg` devuelve **una fila por grupo**; `transform` devuelve **algo del mismo tamaño que el DataFrame**, que puedes comparar fila a fila o usar para rellenar.

## Textos y fechas

Las columnas de texto tienen métodos vectorizados detrás de `.str`: `lower`, `strip`, `split`, `replace`, `contains`, `startswith`, `len`, y los que usan **expresiones regulares**: `extract`, `match`, `findall`. Las fechas, detrás de `.dt` tras convertirlas con `pd.to_datetime`.

## Para llevar

- `apply` es un bucle: prefiere operaciones vectorizadas, `np.where` o `pd.cut`.
- `agg` da una fila por grupo; `transform`, un valor por fila (para comparar o rellenar).
- Tras un `merge`, cuenta las filas: las claves repetidas las multiplican. `validate=` lo vigila.
- `crosstab` y `pivot_table` convierten una tabla larga en una de doble entrada.
- `.str` y `.dt` para textos y fechas; una regex anclada (`$`) es más robusta que un `split`.
