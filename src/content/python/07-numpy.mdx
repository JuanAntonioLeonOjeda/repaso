NumPy es el cimiento de todo el ecosistema: pandas guarda sus columnas en arrays de NumPy, scikit-learn recibe y devuelve arrays, una imagen es un array y un tensor de PyTorch se convierte en uno con `.numpy()`. Su idea es simple: **operar con arrays enteros de golpe, sin bucles de Python**, porque el bucle lo hace C por debajo. Con un millón de números, sumar con un bucle de Python tarda unas cincuenta veces más que `arr.sum()`; puedes medirlo tú con `%timeit` en Jupyter.

## El ndarray

Un `ndarray` es una rejilla de valores **del mismo tipo** (`dtype`) guardados seguidos en memoria. Eso es lo que lo hace rápido, y también lo que lo distingue de una lista.

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
a.shape, a.ndim, a.size, a.dtype      # (2, 3), 2, 6, dtype('int64')

np.zeros((2, 3)); np.ones(4); np.eye(3); np.full((2, 2), 7)
np.arange(0, 10, 2)                   # [0 2 4 6 8]  (como range: excluye el fin)
np.linspace(0, 1, 5)                  # [0. 0.25 0.5 0.75 1.]  (incluye el fin)

rng = np.random.default_rng(42)       # generador con semilla: resultados reproducibles
rng.integers(1, 101, size=50)         # 50 enteros en [1, 100]  (el alto se excluye)
rng.normal(0, 1, size=(3, 3))
```

<Callout kind="real" title="default_rng mejor que np.random.randint">
El curso y los exámenes usan `np.random.randint(1, 101, size=50)`, que sigue funcionando. La recomendación actual de NumPy es crear un generador con `np.random.default_rng(semilla)` y pedirle los números: no depende de un estado global que cualquier otra librería puede alterar, y con la misma semilla obtienes siempre los mismos datos (imprescindible para que un experimento sea reproducible).
</Callout>

### Cambiar de forma

- `a.reshape(3, 2)` reorganiza sin copiar (un `-1` deja que NumPy calcule esa dimensión: `a.reshape(-1)` lo aplana).
- `a.T` traspone; `a.ravel()` aplana (vista si puede), `a.flatten()` aplana copiando.
- `np.concatenate([a, b], axis=0)`, `np.vstack`, `np.hstack` juntan; `np.split` parte.
- `a[np.newaxis, :]` o `a[:, None]` añaden una dimensión de tamaño 1 (útil para *broadcasting*).

## Indexar: vistas, máscaras e índices

```python
m = np.arange(12).reshape(3, 4)
m[1, 2]          # fila 1, columna 2
m[:, 0]          # primera columna
m[-1]            # última fila
m[:2, 1:3]       # submatriz
m[m > 5]         # máscara booleana: los elementos que cumplen (array 1-D)
m[[0, 2]]        # filas 0 y 2 (fancy indexing)
np.where(m > 5, m, 0)   # elegir elemento a elemento: si cumple, m; si no, 0
```

Para combinar condiciones se usan `&`, `|` y `~` **con paréntesis**: `m[(m > 2) & (m % 2 == 0)]`. `and` y `or` no funcionan con arrays.

## Para llevar

- Un `ndarray` tiene un solo `dtype` y vive seguido en memoria: por eso las operaciones vectorizadas son tan rápidas.
- El slicing devuelve **vistas**; las máscaras y el *fancy indexing*, copias.
- Combina condiciones con `&`, `|`, `~` y paréntesis.
- *Broadcasting*: formas alineadas por la derecha, tamaños iguales o 1.
- `axis=0` colapsa filas (un resultado por columna); `axis=1`, columnas.
- `NaN` es float: un array de enteros no puede guardarlo.
