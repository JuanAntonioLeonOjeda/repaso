## Decidir: if, elif, else y match

```python
if nota >= 9:
    calificacion = "sobresaliente"
elif nota >= 5:
    calificacion = "aprobado"
else:
    calificacion = "suspenso"

estado = "par" if n % 2 == 0 else "impar"     # expresión condicional, en una línea
```

Desde Python 3.10 existe `match`, que va más allá de un *switch*: compara **estructuras** y extrae partes.

```python
match punto:
    case (0, 0):
        print("origen")
    case (x, 0):
        print(f"sobre el eje X en {x}")
    case {"nombre": nombre, "edad": edad}:
        print(f"{nombre} tiene {edad} años")
    case _:
        print("otra cosa")
```

## Repetir: for, while y sus ayudantes

`for` recorre cualquier iterable (lista, string, dict, fichero, `range`). Tres ayudantes que te ahorran índices:

- `enumerate(lista)` da pares `(posición, elemento)`.
- `zip(a, b)` recorre dos colecciones a la vez y para en la más corta.
- `range(inicio, fin, paso)`, que como el slicing excluye el fin.

`break` sale del bucle, `continue` salta a la siguiente vuelta, y el `else` de un bucle (poco conocido) se ejecuta **solo si el bucle terminó sin `break`**:

```python
for d in range(2, n):
    if n % d == 0:
        print(n, "no es primo")
        break
else:
    print(n, "es primo")
```

## Primera pregunta de examen: un número perfecto

Un número es **perfecto** si es igual a la suma de sus divisores propios (los divisores menores que él): 6 = 1 + 2 + 3, 28 = 1 + 2 + 4 + 7 + 14.

<CodeExercise

<Callout kind="idea" title="Hacerlo más rápido">
Los divisores vienen en parejas: si `i` divide a `n`, también `n // i`. Basta con recorrer hasta $\sqrt{n}$ y sumar las dos mitades de cada pareja: para 8128 son 90 vueltas en vez de 8127. En un examen vale la versión simple; con números grandes, la diferencia importa.
</Callout>

## Excepciones

Cuando algo va mal, Python **lanza una excepción** (`ValueError`, `KeyError`, `ZeroDivisionError`, `FileNotFoundError`…). Si nadie la captura, el programa se para y muestra el *traceback* (léelo de abajo arriba: la última línea dice qué pasó). Para capturarla:

```python
try:
    valor = float(texto)
except ValueError:
    valor = None          # solo los errores que esperas
else:
    print("convertido")   # si no hubo excepción
finally:
    print("siempre")      # pase lo que pase (cerrar ficheros, conexiones)
```

Y para lanzar las tuyas: `raise ValueError("la edad no puede ser negativa")`.

<Callout kind="warn" title="Nunca «except:» a secas">
Un `except:` o `except Exception:` sin más se traga **todos** los errores, incluidos tus propios bugs (un nombre mal escrito, un índice fuera de rango). El programa sigue «funcionando» con datos incorrectos y nadie se entera. Captura la excepción concreta que esperas y deja que las demás exploten.
</Callout>

## Funciones

```python
def area(base, altura=1.0):
    """Área de un rectángulo."""
    return base * altura

area(3)                    # 3.0  (altura toma el valor por defecto)
area(altura=2, base=5)     # por nombre, en cualquier orden
```

- Una función sin `return` devuelve `None`.
- `return a, b` devuelve **una tupla**, que se desempaqueta: `q, r = divmod(17, 5)`.
- **Parámetros variables**: `*args` recoge los posicionales sobrantes en una tupla y `**kwargs` los nombrados en un dict. Al llamar, `f(*lista)` y `f(**diccionario)` hacen lo contrario: desempaquetan.
- Los argumentos se pasan **por referencia al objeto**: si la función modifica una lista que recibe, el cambio se ve fuera.

### La trampa del valor por defecto mutable

El valor por defecto se evalúa **una sola vez**, cuando se define la función. Si es una lista, todas las llamadas comparten la misma lista. Vuelve a la simulación de la primera lección, escenario «El argumento por defecto mutable», y después arréglalo:

<CodeExercise
  id="defecto-mutable"
  title="Arregla el valor por defecto"

  `}
  solution={`
    def add_item(item, bag=None):

### Lambdas y ordenar con key

Una `lambda` es una función anónima de una expresión: `lambda x: x ** 2`. Su uso estrella es como `key` de `sorted`, `min`, `max` o del `apply` de pandas: la función que dice **por qué** comparar.

### Ámbitos: la regla LEGB

Cuando usas un nombre, Python lo busca en este orden: **L**ocal (la función), **E**nclosing (funciones que la contienen), **G**lobal (el módulo) y **B**uilt-in (`len`, `print`…). Asignar dentro de una función crea una variable **local**, aunque exista una global con el mismo nombre; para modificar la global hace falta `global x` (y casi nunca es buena idea: mejor recibir y devolver).

### Recursividad

Una función recursiva se llama a sí misma con un problema más pequeño, y necesita un **caso base** que pare. Es natural para estructuras anidadas (árboles, JSON, carpetas).

<CodeExercise

  title="Aplanar listas anidadas"
  starter={`

  `}
  solution={`
    def flatten(items):
        resultado = []
        for x in items:

        return resultado

    print(flatten([1, [2, [3, 4], 5], [[6]], 7]))
  `}

  check={`
