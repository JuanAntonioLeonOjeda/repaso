pandas es la hoja de cálculo de Python: tablas con columnas de distinto tipo, con nombre en filas y columnas, que se filtran, se agrupan y se juntan en una línea. La pregunta larga del examen (de 4 a 8 puntos de 10) es siempre un análisis con pandas, así que esta lección y la siguiente son las que más rinden.

## Series: un array con etiquetas

Una `Series` es un array de NumPy de una dimensión con un **índice**: una etiqueta por elemento.

```python
import pandas as pd
precios = pd.Series([2.0, 3.0, 1.5], index=["Coffee", "Cake", "Tea"])
precios["Cake"]          # 3.0   (por etiqueta)
precios[precios > 1.8]   # máscara, como en NumPy
precios * 2              # vectorizado
precios.index, precios.values
```

Al operar dos Series, pandas **alinea por etiqueta**, no por posición: lo que no aparezca en las dos queda `NaN`. Es muy cómodo y, si no lo sabes, muy sorprendente.

### loc frente a iloc

- `.loc[...]` selecciona por **etiqueta**, y en los rangos **el final se incluye**.
- `.iloc[...]` selecciona por **posición** entera, y como en Python el final se excluye.

Usa siempre uno de los dos. `s[1]` es ambiguo: si el índice es de enteros, es la etiqueta 1; si es de texto, versiones antiguas lo tomaban como posición, pero pandas 3 da `KeyError`.

## DataFrame: una tabla

Un `DataFrame` es un diccionario de Series que comparten índice: cada columna es una Series con su propio tipo.

```python
df = pd.read_csv("titanic.csv")        # también read_excel, read_json, read_parquet, read_sql
df.head(6); df.tail(); df.sample(5)
df.shape                               # (filas, columnas)
df.info()                              # tipos y no nulos por columna
df.describe()                          # estadísticos de las columnas numéricas
df["Age"]                              # una columna: Series
df[["Name", "Age"]]                    # varias columnas: DataFrame
df.loc[0, "Name"]; df.iloc[0, 3]       # una celda
df.loc[df["Age"] > 60, ["Name", "Age"]]   # filas por máscara y columnas por nombre
```

Filtrar es lo de NumPy con nombres: `df[(df["Sex"] == "female") & (df["Pclass"] == 1)]`, `df[df["Embarked"].isin(["C", "Q"])]`, `df.query("Age > 60 and Pclass == 1")`. Para ordenar, `sort_values("Fare", ascending=False)`; para contar categorías, `value_counts()`; para crear columnas, `df["familia"] = df["SibSp"] + df["Parch"] + 1`; para quitar, `df.drop(columns=["Cabin"])`.

<Callout kind="real" title="pandas 3: copy-on-write y textos con su tipo">
En pandas 3 (la versión de esta web) han cambiado dos cosas que verás en tutoriales antiguos:

- **Copy-on-write**: el famoso `SettingWithCopyWarning` desaparece. Un filtro siempre se comporta como una copia, así que `df[df.Age > 60]["Fare"] = 0` **no modifica `df`** (y pandas avisa con un `ChainedAssignmentError`). Para modificar, una sola operación: `df.loc[df.Age > 60, "Fare"] = 0`.
- Las columnas de texto tienen tipo `str` en vez de `object`.

Y evita `inplace=True`: no ahorra memoria y estorba para encadenar operaciones. Mejor `df = df.dropna(...)`.
</Callout>

<Callout kind="warn" title="El porcentaje de nulos de la solución del examen">
En la solución que circula de la primera convocatoria se calcula `isnull().sum() / count() * 100`. Pero `count()` cuenta solo los **no nulos**, así que el resultado no es el porcentaje sobre el total (con un 50 % de nulos daría 100 %). Lo correcto es dividir entre `len(df)`, o directamente `df.isna().mean() * 100`.
</Callout>

## Valores perdidos

pandas representa lo que falta con `NaN` (y `NaT` en fechas, `pd.NA` en algunos tipos). Las herramientas:

- Detectar: `df.isna()`, `df.isna().sum()` (por columna), `df.isna().sum(axis=1)` (por fila).
- Quitar: `df.dropna()` (filas con algún NaN), `dropna(subset=["Item", "Location"])`, `dropna(how="all")`, `dropna(axis=1, thresh=8)`.
- Sustituir: `df.mask(cond, np.nan)` pone NaN donde se cumple; `df.where(cond, otro)` conserva donde se cumple. `replace(["ERROR", "UNKNOWN"], np.nan)`.
- Rellenar: `fillna(valor)`, `fillna(df.mean())`, `ffill()`, `bfill()`, `interpolate()`.

## Para llevar

- Una Series es un array con índice; al operar, pandas alinea por etiqueta.
- `.loc` por etiqueta (incluye el final), `.iloc` por posición (lo excluye).
- Filtra con máscaras entre paréntesis y `&`; para modificar, una sola operación con `.loc`.
- Porcentaje de nulos: `df.isna().mean() * 100`.
- `mask`/`where` para sustituir, `dropna(subset=...)` para quitar, `interpolate().ffill().bfill()` para no dejar huecos.
