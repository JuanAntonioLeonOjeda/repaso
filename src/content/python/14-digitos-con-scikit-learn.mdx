## ¿En qué se equivoca?

La accuracy dice cuánto acierta; la **matriz de confusión** dice **qué confunde con qué**: la fila es el dígito real y la columna el predicho, así que todo lo que está fuera de la diagonal son errores.

    import numpy as np
    from sklearn import datasets, metrics, svm
    from sklearn.model_selection import train_test_split

    digits = datasets.load_digits()
    X = digits.images.reshape(len(digits.images), -1)
    X_train, X_test, y_train, y_test = train_test_split(X, digits.target, test_size=0.5, shuffle=False)
    pred = svm.SVC(gamma=0.001).fit(X_train, y_train).predict(X_test)

    cm = metrics.confusion_matrix(y_test, pred)
    errores = cm.copy()
    np.fill_diagonal(errores, 0)
    real, predicho = np.unravel_index(errores.argmax(), errores.shape)

## Un hiperparámetro mal elegido

`gamma` controla lo «local» que es el núcleo gaussiano del SVM: con un `gamma` grande, cada imagen de entrenamiento solo influye en las que se le parecen muchísimo.

<Callout kind="real" title="Del ejemplo a un proyecto">

Este ejemplo usa justo las piezas que verás en Aprendizaje Supervisado y en Deep Learning.
</Callout>

## Para llevar

- scikit-learn espera una tabla: una fila por muestra. Las imágenes se aplanan con `reshape(n, -1)`.
- La interfaz es siempre la misma: crear, `fit`, `predict`, evaluar.
- La matriz de confusión dice qué se confunde con qué; aquí, sobre todo, el 3 con el 8.
- 100 % en entrenamiento y 10 % en prueba es sobreajuste: los hiperparámetros importan.
- Un test diminuto da una cifra con mucho ruido.
